# أكاديمية نور البيان

موقع محلي عربي متجاوب لأكاديمية تحفيظ القرآن الكريم وتعليم التجويد.

## التشغيل

```bash
python3 -m http.server 4174
```

ثم افتح `http://localhost:4174`.

## التخصيص قبل النشر

- غيّر رقم واتساب الأكاديمية داخل `app.js` بدل الرقم التجريبي `201000000000`.
- حدّث أسماء المعلمين والبرامج وبيانات التواصل داخل `index.html`.
- يمكن رفع الملفات على أي استضافة Static مثل GitHub Pages أو Netlify أو Vercel.
- نموذج التسجيل يجهز رسالة واتساب ولا يخزن بيانات الطلاب في قاعدة بيانات.
